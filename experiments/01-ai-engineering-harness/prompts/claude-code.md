# Claude Code: instrucción de la ejecución

1. Restaura la línea base del repositorio temporal antes de ejecutar.
2. Abre VS Code en C:\Evolium\webinar-experiment-01-live y verifica la ruta con Get-Location.
3. Inicia Claude Code desde la terminal integrada con el comando claude.
4. Copia y envía **exactamente** el mismo mensaje de [mensaje-unico.md](mensaje-unico.md) utilizado en Claude Web.
5. Permite lectura de documentos, cambios del código y pruebas. No permitas commit ni push.
6. Verifica el resultado independientemente con unittest, git diff y git diff --check.

**No uses un prompt alternativo:** la comparación exige que ambas interfaces reciban las mismas instrucciones.
