# Codex: alternativa de ejecución

Codex queda como **alternativa** si Claude Code no está disponible. No es parte de la comparación principal con Claude Web porque cambiaría también el asistente.

Si usas Codex, inicia la herramienta desde la raíz del repositorio temporal y envía **exactamente** el texto de [mensaje-unico.md](mensaje-unico.md), respetando todos los documentos y criterios. No permitas commit ni push.

Registra en la bitácora el cambio de herramienta y evita concluir que una diferencia se debió únicamente al entorno.
