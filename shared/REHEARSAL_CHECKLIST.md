# Lista de Ensayo

## Antes del webinar
- Presentación autenticada y abierta.
- VS Code abierto en el workspace del Experimento 01.
- Claude Desktop o ChatGPT Desktop en una conversación nueva.
- Claude Code y Codex autenticados.
- Experimento 01 restaurado a su línea base.
- Línea base verificada: exactamente una prueba falla intencionalmente.
- UI del extractor bancario ejecutándose localmente.
- PDF de demostración seguro preparado.
- Credenciales cargadas sin mostrarlas en pantalla.
- Terminal con fuente grande.
- Notificaciones desactivadas.
- Ventanas ordenadas antes de empezar.
- Evidencia/capturas de respaldo disponibles para ambos experimentos.

## Durante el webinar
- No mostrar `.env`, claves API, secretos, datos bancarios privados ni historial de terminal sensible.
- No instalar dependencias en vivo.
- No programar manualmente salvo que sea parte de preguntas posteriores.
- Usar un solo harness en el Experimento 01.
- Mantener cada experimento por debajo de cinco minutos.
